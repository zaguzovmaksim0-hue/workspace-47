Wave A deliberately leaves DGOJ navigation-only. The reviewed homepage login link opens target="_blank", while BrowserScreen requires a user gesture for popup creation and launches popup content without a trusted certificate profile. The existing JavaScript exact-click recipe cannot safely preserve the Cl@ve client-auth grant through that route; adding popup trust inheritance is outside the authorized security model. Revisit only with a separately reviewed in-place route or an explicit owner decision about popup isolation.
