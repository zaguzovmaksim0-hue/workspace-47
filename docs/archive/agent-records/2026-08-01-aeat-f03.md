## Exact point where execution stopped

The target `Mis datos censales` was **observed but not clicked**.

Reason: the Android Control Bridge application repeatedly brought
`io.termux.androidcontrol/.MainActivity` to the foreground while accessibility
operations were attempted. The first exact-click attempt consequently inspected
the control application's UI instead of the AEAT WebView and was rejected.

The control UI was then force-stopped and `Junta Firma` was restored to
foreground. A subsequent `uiautomator dump` returned empty. No coordinate guess
or blind tap was used.

Therefore these facts are **not yet proven**:

- Android WebView `ClientCertRequest` callback observed for the AEAT target;
- exact runtime request host/port/key-types/issuer metadata from that callback;
- native certificate confirmation shown;
- AEAT accepted certificate authentication;
- authenticated read-only `Mis datos censales` landing reached.

Do not promote the profile based only on `WEBVIEW_ACTIVE`.
