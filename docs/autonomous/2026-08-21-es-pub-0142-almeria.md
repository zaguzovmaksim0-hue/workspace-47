# ES-PUB-0142 — Diputación Provincial de Almería

Reviewed: 2026-08-21

## Decisive current evidence

- The public Sede surface is reachable over valid HTTPS at `https://www.dipalme.org/Servicios/cmsdipro/index.nsf/index.xsp?p=sededipalme`.
- Its current services page exposes the exact `Acceso al Registro Electrónico` link to `https://ov.dipalme.org/TiProceeding/ciudadano?entrada=ciudadano&idLogica=accesoDirecto&idExpediente=800210_SolicitudGeneral&idEntidad=400000`.
- The exact Oficina Virtual target responded HTTP 200 on review with no preliminary redirect and identifies the requested flow as electronic procedures for Diputación Provincial de Almería. It states that access is via Cl@ve and that an existing certificate can be used without prior Cl@ve registration.
- Direct TLS verification of the `sede.dipalme.org` vanity host failed during this review because its presented certificate was expired, so that vanity host is not used as the QA start/trust origin.

## Implemented boundary

The candidate adds a QA-only navigation profile for the exact Solicitud General / Registro Electrónico launch on `ov.dipalme.org`. It deliberately exposes no signing, certificate-selection, bridge or `CLIENT_TLS_AUTH` capability. Certificate access is recorded only as an observed optional identification mechanism. No authentication, private-key signature, final filing, registration or payment was performed.
