# ES-PUB-0039 — Dirección General de Fondos Europeos public Sede boundary

Reviewed 2026-08-24 using unauthenticated first-party HTTPS navigation only. The canonical root `https://sedefondoscomunitarios.gob.es/` negotiates TLS 1.2 with a certificate issued to the Dirección General de Fondos Europeos and redirects on the same origin to the live Sede landing, which returned HTTP 200. The landing identifies the electronic Sede, lists electronic services, procedure-status consultation, telematic notifications, registry information, electronic-signature information, document verification, and other public navigation.

The public services page exposes operational links on separate origins, including Hacienda/IGAE, `tramitesfondoseuropeos.hacienda.gob.es`, and a RED SARA registry URL. Those origins are not imported into this profile. The first-party signature page states only the general AGE electronic-signature/certificate policy; it does not provide an exact signer ABI, algorithm, format, packaging, callback, certificate-selection bridge, or client-TLS contract.

Therefore the implemented contract is exact QA-only public navigation on `sedefondoscomunitarios.gob.es`. Authentication, certificate selection, client TLS, SIGN, external services, notifications, and final filing remain fail-closed and outside trust. No certificate was selected, no authentication was completed, no document was uploaded or signed, and no administrative submission was made. Transient SharePoint cookies/request identifiers observed during public HTTP access were not stored in the repository.
