# ES-PUB-0155 — Diputación Provincial de Granada — bounded public evidence

Reviewed 2026-08-23. The official portal `https://www.dipgra.es/` exposes a first-party “Sede electrónica” link to `https://sede.dipgra.es/`. The Sede resolves publicly through its OpenCms landing and exposes “REGISTRO ELECTRÓNICO”, a stable identification link, “Firmas electrónicas admitidas”, and an AutoFirma requirement for PC identification/signing contexts.

The Sede’s procedure navigation is generated with a POST form (`action=generaTicket`) carrying `area` / `procedure` parameters. Those ticket transitions are not treated as stable start URLs and no session material is retained. This candidate therefore binds only the stable public Sede root as QA-only trusted browse. It does not enable SIGN, SELECT_CERTIFICATE, CLIENT_TLS_AUTH, AutoFirma bridge behavior, callbacks, payment, filing or final submission.
